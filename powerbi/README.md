# Workflow Performance Dashboard (Power BI)

## Overview

This Power BI dashboard complements the Streamlit dashboard by providing an interactive business intelligence report for workflow performance monitoring.

The dashboard uses the KPI tables generated during the Python and SQL analysis.

## Data Sources

The report imports:

- data/kpis/activity_frequency.csv
- data/kpis/case_duration_categories.csv
- data/kpis/rework_by_duration.csv
- data/kpis/key_transition_comparison.csv
- data/kpis/waiting_time_summary.csv
- data/kpis/resource_workload.csv

## Dashboard Pages

1. Process Overview
2. Rework Analysis
3. Waiting Time & Bottlenecks
4. Resource Workload

## Purpose

The goal of this dashboard is to provide business users with an interactive interface for monitoring workflow efficiency, identifying bottlenecks, and supporting operational decision-making.
